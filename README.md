# 💡 Light Bulb

An interactive lighting experience built with HTML, CSS and JavaScript.

## Features

- Interactive light bulb with on/off controls
- Four ambient light colors
- Adjustable brightness
- Live interaction counter
- Responsive design for mobile and desktop
- Accessible controls and reduced-motion support
- No external libraries or dependencies

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
